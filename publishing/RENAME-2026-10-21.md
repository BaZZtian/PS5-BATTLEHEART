# BattleHeart name change

On 21 October 2026 the owner requested the project name BattleHeart, matching
the chat title. GitHub already redirects the former repository URL to
https://github.com/BaZZtian/PS5-BATTLEHEART . Project documentation, CMake
project name, metadata and local remote now use the current name.

Store change request: https://github.com/darkxex/ps5-homebrew-catalog/pull/484

The request changes only the name and description prefix of PPSA99732 from
OpenSA2B PS5 to BattleHeart. It preserves the existing title ID and all other
catalog fields. At submission it is open and awaits maintainer approval.
The local coming-soon JSON is the proposed record until the request is merged.

Version v0.0.1 and its tag stay unchanged; this is a naming/documentation update.
Historical submission notes and screenshots retain the original name as evidence.
No game files or new binary release are part of this change.
